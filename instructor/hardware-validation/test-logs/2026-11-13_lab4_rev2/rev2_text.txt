[Normal] Pick-and-Place: Teach Pendant Programming and MATLAB RTDE Control
[Normal] Accompanying MATLAB file(s):  UR_PickPlace_Lab.m, check_waypoints.p
[Heading 1] Overview
[Normal] In this lab you will program a UR e-series robot to pick up a cube and place it at a second location. You will do it twice: first with a program built on the Teach Pendant, and then from MATLAB over the RTDE connection that you set up in Lab 2.
[Normal] The overall objective is to record one set of waypoints, run the same task with both methods, and compare the two workflows.
[Heading 1] Learning Objectives
[List Bullet] Design a waypoint sequence for a pick-and-place task, including the approach and retract points, and record it with the Teach Pendant.
[List Bullet] Build and safely test a pick-and-place program on the Teach Pendant using joint moves (MoveJ), linear moves (MoveL) and gripper commands.
[List Bullet] Run the same sequence from MATLAB over RTDE, after verifying the connection against the Teach Pendant readout.
[List Bullet] Compare the two workflows and justify which one fits a given automation task.
[Heading 1] Background: Move Types and Approach Waypoints
[Normal] Every waypoint in this lab is recorded as six joint angles in degrees, in order from joint 1 (base) to joint 6 (wrist 3), exactly as the Teach Pendant displays them. These are the hardware angles theta_hw of Lab 3.
[Normal] The robot can travel between two waypoints in two ways. A joint move (MoveJ; the Joint Move node on the Teach Pendant) turns all six joints together so that they finish at the same time. It is the fastest way to travel, but the TCP follows a curved path. A linear move (MoveL; the Linear Move node) drives the TCP along a straight line. It is used for the short vertical moves down onto the cube and back up.
[Normal] A pick-and-place task therefore uses approach waypoints. The gripper first moves to a point directly above the cube, descends straight down, grips, and rises straight back up before it travels sideways. Without the approach waypoints the gripper would sweep in at an angle and push the cube or hit the table.
[Normal] UR_PickPlace_Lab.m uses the functions you ran in Lab 2 and requires the same server script to be running on the robot. Table 1 lists only what is new in this lab.
[Normal] Table 1: MATLAB functions and options that are new in this lab
  | Function | What is new
  | ur = urRTDEClient(robotIP, 'CobotName', 'universalUR3e') | CobotName names the robot model, so that MATLAB uses the dimensions of your robot.
  | sendJointConfigurationAndWait(ur, q, EndTime = t) | EndTime schedules the move to take t seconds.
  | pose = readCartesianPose(ur) | Returns a 1x6 vector: three orientation angles in radians, then the X, Y, Z position of the tool flange in meters (elements 4 to 6).
  | actuateGripper(ur, 'grip') and actuateGripper(ur, 'release') | Closes or opens the Robotiq gripper.
[Normal] 
[Normal] You enter and read every angle in degrees. The script converts to and from radians.

[Heading 1] Part 1 - Define the Waypoints
[Normal] The task uses the six waypoints of Table 2. The robot visits them in this order: Ready, Pre-Pick, Pick (close the gripper), Retract, Pre-Place, Place (open the gripper), Pre-Place, Ready. The gripper is also opened once at Ready, before the first approach.
[Normal] Table 2: Waypoint definitions and the Teach Pendant node used to reach each one
  | Waypoint | Node | Definition
  | Ready | Joint Move | The start and end pose, chosen by you: shoulder and elbow bent, tool flange facing down, gripper well above the table (Figure 1).
  | Pre-Pick | Joint Move | The approach point: directly above the cube, 5 to 10 cm higher than Pick, with the same gripper orientation.
  | Pick | Linear Move | The open gripper fingers are on either side of the cube, just above the table. The gripper closes here.
  | Retract | Linear Move | Straight back up from Pick with the cube. This is the same pose as Pre-Pick, so it takes the same values.
  | Pre-Place | Joint Move | The approach point directly above the place location, 5 to 10 cm higher than Place.
  | Place | Linear Move | The cube rests on the place location. The gripper opens here.
[Normal] 
[Normal] 
[Normal] Figure 1: An example ready position, seen from the side: shoulder and elbow bent, tool flange facing down. The Teach Pendant joint angles of this pose are [0, −80, −80, −110, 90, 0] degrees.

[Heading 1] Part 3 - MATLAB RTDE Program
[Normal] UR_PickPlace_Lab.m runs the same eleven steps from MATLAB. It connects to the robot, prints the current joint angles, and then moves through the waypoints you type into it. All of its moves are joint moves, and it opens and closes the gripper through the server script. Three safeguards are built in. Each waypoint starts as NaN, and the script stops before any motion while a NaN remains. It then runs check_waypoints.p, which computes where each waypoint puts the gripper and prints PASS or FAIL for eight checks, for example that Pre-Pick is directly above Pick and that the gripper points straight down. The robot does not move while any check fails. Finally the script asks you to type yes before the robot moves.

[Normal] If the script stops with an error:
[List Bullet] "Robot did not reach ...": the server script is not running, the robot is in a protective stop, or the speed slider is below 10%. Clear the stop on the Teach Pendant, press Play so that the node is green again, and rerun the script.
